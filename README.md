# 🏥 Medical AI: Neural Network Diabetes Risk Predictor

This repository contains a fully functioning **Artificial Neural Network (ANN)** built from scratch to calculate metabolic health and diabetes risk using patient clinical metrics.

## 🧠 Why This Project Exists (Scholarship Intent)
As a **Pre-Medical student with an 80.2% academic baseline**, I wanted to actively bridge the gap between my foundational biological knowledge and my future career goals in **Artificial Intelligence and Data Science**. Instead of waiting for university to start, I took the initiative to self-taught the fundamentals of Python and Deep Learning to build this predictive diagnostic system for the **Türkiye Bursları Scholarship**.

## 🛠️ Tech Stack
* **Language:** Python 3
* **Framework:** TensorFlow & Keras (Deep Learning)
* **Libraries:** Pandas (Data Handling), Scikit-Learn (Data Preprocessing)

## 📊 How the Brain Works
1. **StandardScaler Normalization:** Normalizes input metric ranges so synaptic weight adjustments scale optimally during training loops.
2. **Dense Hidden Layers:** Utilizes **ReLU** activation functions across multi-layered hidden nodes to calculate non-linear patient dependencies.
3. **Sigmoid Optimization:** Squashes the final numeric output signal into a crisp clinical prediction probability between 0% and 100%.
